# LHolo

[English](docs/README_EN.md)

`LHolo` 是一个 [LeviLamina](https://github.com/LiteLDev/LeviLamina) 客户端投影模组

## 版本号说明

示例版本：`v26.51.2`

- `26.51`：对应的 Minecraft 游戏版本
- `.2`：模组在该游戏版本下的第 2 个版本

## 快速上手

[安装教程](https://www.bilibili.com/opus/1239631121935761412)

1. 安装本模组以后,聊天栏输入 `LHolo`,或按 `Alt + M` 打开模组菜单
2. 本模组交互为GUI与快捷键(具体快捷键直接看模组菜单)
3. 使用本模组时,请关闭灵动视效

## 主要功能

**文件支持**

- 支持 `.mcstructure` 和 `.litematic`(Java 版 Litematica 蓝图)两种文件

**纠错**

- 蓝色 = 未放置投影方块
- 红色 = 方块放置错误
- 黄色 = 朝向或状态错误
- 品红色 = 多余方块

**分层建造**

- 按 X 轴切片或 Y 轴水平层显示
- 按材料清单顺序分层显示
- 支持显示全部、单层、当前层及以下、当前层及以上
- 可使用菜单中的分层快捷键调整当前层

**结构变换**

- 移动
- 旋转 
- 镜像

**HUD 信息显示**

- 屏幕角落可显示:蓝图文件名、当前显示的层、建造进度(已放/总数)、各类错误数量、当前辅助放置模式等。
- 位置可放在屏幕四角,每一项都能单独开关。

**辅助放置**

- 轻松放置和范围放置会在投影缺失位置自动放置方块，手动放置支持按住右键连续放置。
- 观察者、活塞、投掷器、发射器、漏斗等有方向的方块会先检查预计朝向，无法匹配时不会错误放置。
- 水和熔岩按水桶、熔岩桶处理。
- 可选开启“自动清除阻挡方块”，仅清除投影缺失位置上的实际方块；开启前请确认手持工具能够破坏目标方块。
- 辅助放置为当前游戏会话设置，不会自动写入配置文件。

**多语言支持**

- 简体中文
- English
